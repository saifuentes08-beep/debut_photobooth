# Our Little Memory Booth — starter v2

This version includes:
- A choice between **One Polaroid** and **Four-photo strip**
- Four-photo mode where guests manually tap Capture for each pose
- Preview, retake, and download as a JPEG
- Mobile-friendly layout for Android and iPhone browsers

## Try it
Camera access usually requires HTTPS. The easiest free route is GitHub Pages.

1. Sign in or create a free GitHub account at https://github.com/
2. Create a public repository named `debut-photo-booth`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then Save.
7. Wait for the published URL to appear. Open it on your phone and allow camera access.

You can upload `README.md` too, but only `index.html` is needed for the site. After editing `index.html` in GitHub, commit the change; Pages will publish the update and the site URL usually stays the same.

## Important
- This starter does **not** upload photos to a shared gallery yet. Photos stay in the current browser session unless a guest downloads them.
- Camera access needs HTTPS and permission.
- Test on an Android phone and an iPhone before your event.
- To protect guests' privacy, tell them how photos will be used before adding any shared-gallery feature.
- Customize the title, colors, and frame text in `index.html` later.
